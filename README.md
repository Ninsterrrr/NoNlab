# NoNlab - 贴图批量压缩模块 
(Texture Batch Compression Tool)

一个为 Unity 开发者设计的极致轻量化、高效贴图批量处理工具。
通过拖拽即可快速批量修改贴图尺寸、压缩格式，减轻负载。毕竟高精度贴图超级吃配置。
建议用于VRCHAT改模（我写它的本意）

- 当前版本：V1.01
- 总大小：约10Kb
- By:Ninster-NoNlab
---

## 功能特性 (Features)

- 拖拽式操作：支持将模型、材质、贴图文件夹直接拖入窗口，自动收集关联贴图。
- 批量处理：一键将贴图压缩至4096 / 2048 / 1024 / 512 / 256 / 128 / 64 / 32等目标尺寸。
- 可自动识别法线贴图 (Normal Map)、遮罩贴图 (Mask) 等，并推荐合适的压缩格式。
- 实时统计：直观显示贴图总大小、目标大小以及预计节省的空间百分比。
- 精细控制：提供详细设置面板，支持“全部勾选/取消”、“自动识别法线”、“全部设为 None / 低质量 / 普通/法线 / 高质量”等快捷操作。
- 支持“撤销”功能，防止误操作导致贴图被永久修改。

## 使用方法 (Usage)

1. 打开工具：点击 Unity 顶部菜单 NoNlab -> 贴图批量压缩模块。
2. 添加贴图：
   - 将模型、材质、贴图文件或整个文件夹直接拖入中央的虚线框区域。
   - 工具会自动解析并列出所有关联的贴图文件。
3. 配置设置：
   - 点击底部的 [详细设置(推荐)] 按钮，打开详细配置面板。
   - 在列表中勾选需要处理的贴图。
   - 选择目标尺寸（如 1024、512）和压缩格式（如普通/法线、高质量等）。
   - 或者使用顶部的快捷按钮（如“全部压缩至 2048”、“自动识别法线”）进行批量设置。
4. 应用处理：
   - 确认设置无误后，点击 [应用] 按钮。工具将自动修改贴图的导入设置。
   - 如果操作有误，可以点击 [撤销] 恢复到修改前的状态。

## 常见问题 (FAQ)

Q: 为什么我拖入模型后，没有收集到任何贴图？
A: 请确保您的模型材质使用的是 Unity 标准材质或常见的 Standard Shader，且贴图已经正确赋值。如果贴图没有关联到材质上，工具无法自动识别。

Q: 压缩后贴图变模糊了怎么办？
A: 压缩尺寸和格式会直接影响画质。建议对 UI 或重要道具使用 2048/1024，对远景或小物件使用 512/256。您可以在详细设置中单独调整每张贴图的参数。

Q: 我的修改可以撤销吗？
A: 可以。在未关闭窗口的情况下，点击底部的“撤销”按钮即可回退到本次操作前的状态。但建议在操作前备份项目。
